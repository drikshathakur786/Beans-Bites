# Sample Data Files

- `UserSampleData.json` -> `[User]`
- `CoffeeSampleData.json` -> `CoffeeSnapshot` (`beans`, `pairingGuides`)
- `BrewSampleData.json` -> `[BrewRitual]`
- `DiscoverSampleData.json` -> `DiscoverSnapshot` (`categories`, `editorials`, `recentSearches`)
- `CommunitySampleData.json` -> `CommunitySnapshot` (`posts`, `draft`)
- `ProfileSampleData.json` -> `[ProfileData]`
- `AuthSessionSampleData.json` -> `AuthSession`
- `AppNavigationSampleData.json` -> `AppNavigationState`
- `AppStateSampleData.json` -> `AppStateSnapshot`

All dates use ISO-8601 UTC format.
